# University Timetable Scheduler

A professional university scheduling system built with OR-Tools CP-SAT and Flet UI.

## Features

- **Interval-based OR-Tools modeling**: Supports multi-period lectures naturally
- **Modular architecture**: Clean separation of concerns
- **Modern UI**: tkinter-based desktop interface
- **Multiple exports**: Excel, CSV, and PDF export capabilities
- **Comprehensive statistics**: Room utilization, teacher workload, student metrics
- **Real-time solving**: Background solver with cancellation support
- **Weighted optimization**: Configurable objective weights

## Installation

```bash
pip install -r requirements.txt
```
